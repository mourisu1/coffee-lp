# coffee-lp

Café Douce（カフェ・ドゥース）のコーヒーショップ向けホームページ（LP）です。

ドトールコーヒーショップ（https://www.doutor.co.jp/dcs/ ）のような、お知らせ・こだわり紹介・おすすめメニュー・店舗情報・SNSを備えた構成を参考にしたオリジナルデザインです。

## 構成

```
index.html            トップページ本体
assets/css/style.css  スタイルシート
assets/js/main.js     ハンバーガーメニュー / スクロールアニメーション等
```

## ページ内セクション

- ヒーロー（メインビジュアル）
- お知らせ（News）
- こだわり（Concept）
- おすすめメニュー（Menu）
- 季節限定バナー
- 店舗情報（地図付き）
- Instagram
- 公式アプリ会員募集バナー
- お問い合わせ

## 画像について

写真はUnsplashのフリー素材（Unsplash License）を直接読み込む形で使用しています。読み込みに失敗した場合は自動的にコーヒーカラーのプレースホルダー表示に切り替わります。

## 表示方法

`index.html` をブラウザで直接開くか、リポジトリ直下で簡易サーバーを立てて確認してください。

```
python3 -m http.server 8000
```

その後 `http://localhost:8000` にアクセスします。
