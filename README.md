# ひなた薬局 薬剤師採用LP

小規模な調剤薬局の薬剤師求人向けランディングページです。建築図面（シート番号・寸法線・平面図）のモチーフに、葉っぱのラインアートを重ね、「真面目でアットホーム、ほんの少しゆるふわ」なトーンで構成しています。

## 構成

- `index.html` — ページ本体
- `css/style.css` — スタイル(ライト/ダークテーマ対応)
- `js/main.js` — アコーディオン・モバイルメニュー・スクロール演出・応募フォームの送信デモ

## 使い方

`index.html` をブラウザで開くだけで確認できます。ビルド不要の静的サイトです。

掲載する薬局名・住所・給与・待遇などの内容はすべてサンプルです。実際の運用前に必ず自薬局の情報に差し替えてください。応募フォームは現状クライアント側の完了表示のみのデモ実装のため、実際に送信先へ届けるにはメール送信サービスや自社サーバーとの連携が必要です。
