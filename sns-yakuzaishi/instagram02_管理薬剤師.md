# Instagram展開:2本目「管理薬剤師の後悔と良かったこと」

## カルーセル(7枚)
指標は保存数とプロフィールアクセス。1枚目でフックを作り、最後にnoteへ誘導する。

1. 【表紙】3年目で管理薬剤師になった私が 一番後悔したこと
   サブ:調剤薬局18年・転職8回の薬剤師
2. 【共感】打診されて「驚いた」
   でも挑戦できたのは、伴走してくれる上司がいたから
3. 【後悔①】「優しさだけ」では店は回らなかった
   ・自分が業務を被る → 店全体への配慮が不足
   ・優先順位を決めて伝えるのも、管理者の優しさ
4. 【後悔②③】見えない仕事と、家族との時間
   ・シフト、棚卸、休日当番(携帯が鳴るたびにドキドキ)
   ・週5日22時帰宅。子どもも妻も床で寝ていた日も
5. 【失敗談】高い薬を開封してから規格違いに気づいた
   パニック → 数日後に冷静 → 卸さんに頼みまくって引き取ってもらった
   学び:隠さず早く報告。助けてくれるのは日ごろの信頼
6. 【良かったこと】判断力は「訓練」でつく
   視野は広げるのではなく、業務を無意識にできるようにする(車の運転のたとえ)
7. 【締め】自分にとっての最良の場所は、時期ごとに違う
   選ぶ権利は自分にある
   詳しくはnoteへ(プロフのリンク)
